# 💌 Open When Letters — Private Edition

A personal, encrypted "Open When" letters app for sharing with one special friend.

## 🔐 Encryption
- **AES-256-GCM** via the Web Crypto API (browser-native, zero dependencies)
- Letters are encrypted in-browser before storage
- Only someone with the **passphrase** can read the letters
- The passphrase never leaves the browser

## 🚀 How to Use

### As the Sender (You)
1. Open `index.html` in a browser
2. Click **"Write Letters"** and enter your secret passphrase
3. Write letters for each "Open When" moment
4. Click **Export** — it downloads an encrypted `letters.json` file
5. Send `letters.json` + `index.html` to your friend (or host on GitHub Pages)

### As the Receiver (Your Friend)
1. Open `index.html`
2. Click **"Read Letters"** and upload the `letters.json` file
3. Enter the passphrase you shared
4. Choose a letter to open 💌

## 📁 Files
- `index.html` — the entire app (self-contained)
- `letters.json` — encrypted letters (generated by you)

## 🛡️ Security Notes
- AES-256-GCM provides authenticated encryption (tamper-proof)
- Key is derived via **PBKDF2** with 310,000 iterations + random salt
- Each letter gets a unique random IV
- No server, no backend, no tracking
