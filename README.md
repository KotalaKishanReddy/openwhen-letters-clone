# 💌 Open When Letters — Private Edition

A visually stunning, personal, encrypted "Open When" letters app for sharing with one special friend.

## ✨ Features

- **Rich text editor** — bold, italic, underline, fonts, colors, text alignment
- **Photo attachments** — drag & drop photos, displayed as polaroids
- **Paper themes** — Cream, Rose, Sky, Mint, Lavender, Gold, Night
- **Sticker bar** — quick insert emoji stickers into letters
- **Envelope cards** — beautiful animated envelopes in the read view
- **Floating particle animation** — hearts and envelopes float in background
- **AES-256-GCM encryption** — letters AND photos encrypted together
- **PBKDF2-SHA256 key derivation** — 310,000 iterations
- **100% offline** — no server, no backend, no tracking

## 🔐 Encryption
- **AES-256-GCM** via Web Crypto API (browser-native, zero dependencies)
- **PBKDF2-SHA256** with 310,000 iterations + random 16-byte salt
- Photos are Base64-encoded and encrypted inside the same GCM payload
- Passphrase never leaves your browser

## 🚀 How to Use

### As the Sender (You)
1. Open `index.html` in any browser
2. Click **Write Letters** → set a passphrase and recipient name
3. Pick a paper theme, write your letter with rich formatting
4. Attach photos (drag & drop or click)
5. Add stickers and choose emojis
6. Click **Add to Collection** → repeat for all letters
7. Click **Export Encrypted File** → downloads `letters.json`
8. Send your friend: `index.html` + `letters.json`
9. Share the passphrase via call / in-person

### As the Receiver (Your Friend)
1. Open `index.html`
2. **Read Letters** tab → upload `letters.json`, enter passphrase
3. Click any envelope to open that letter 💌

## 📁 Files
- `index.html` — the entire app (self-contained, zero dependencies)
- `letters.json` — encrypted letters (generated by you, share with friend)

## 🛡️ Security Notes
- AES-256-GCM = authenticated encryption (tamper-proof)
- PBKDF2 with 310k iterations = brute-force resistant
- Each letter has a unique random IV
- Without the passphrase, ciphertext is indistinguishable from random noise
- Deploy to GitHub Pages for a shareable URL (Settings → Pages → main branch)
