# openwhen-letters-clone

A pixel-perfect static clone of [openwhenletters.app](https://openwhenletters.app/) — built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools.

## Features

- ✉️ Faithful recreation of the landing page layout and design
- 🎨 Warm cream/brown/pink color palette matching the original
- 🃏 Auto-scrolling letter card strip with tilt hover effect
- 📖 3-step "How it works" section with visual mockups
- ❓ Animated FAQ accordion with smooth open/close
- 📱 Fully responsive (mobile, tablet, desktop)
- 🔤 Google Fonts: Instrument Serif + Inter
- ⚡ Zero dependencies — just open `index.html` in a browser

## Structure

```
openwhen-letters-clone/
├── index.html   # Full page markup
├── style.css    # All styles (CSS variables, responsive)
├── script.js    # Interactions (FAQ, scroll spy, card tilt)
└── README.md
```

## Usage

```bash
git clone https://github.com/KotalaKishanReddy/openwhen-letters-clone.git
cd openwhen-letters-clone
# open index.html in your browser — no build step needed
```

Or deploy instantly to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or [GitHub Pages](https://pages.github.com).

## Deploy to GitHub Pages

1. Go to **Settings → Pages**
2. Set source to **Deploy from branch → main → / (root)**
3. Save → your site will be live at `https://KotalaKishanReddy.github.io/openwhen-letters-clone`
