🔐 Encryption Details

This app uses mathematically proven, industry-standard encryption. Here's exactly what happens:

1. Key Derivation — PBKDF2-SHA256

Your passphrase is never used directly. It's fed into PBKDF2 (Password-Based Key Derivation Function 2) with 310,000 iterations, a random 16-byte salt, using SHA-256. This makes brute-force attacks astronomically expensive. The output is a 256-bit cryptographic key.

2. Encryption — AES-256-GCM

Each letter is encrypted independently using AES-256 in GCM mode (Galois/Counter Mode). GCM is an authenticated encryption scheme — it provides both confidentiality AND integrity. Any tampering with the ciphertext is detected. Each letter gets a unique random 12-byte IV.

3. Web Crypto API

All cryptographic operations use the browser's built-in SubtleCrypto API — the same API used by banks and governments. No third-party crypto libraries. No JavaScript shims. Cryptographically secure random numbers from crypto.getRandomValues().

4. Zero Server, Zero Tracking

Everything runs 100% in the browser. Your passphrase and decrypted letters never leave your device. There are no cookies, no analytics, no network requests. The encrypted file is a plain JSON you control entirely.

📋 Encrypted File Format

{{
  "v": 1,
  "salt": "",
  "greeting": "",
  "letters": [
    {{
      "iv": "",
      "ct": "",
      "emoji": "💌"

  ]

The salt is shared (not secret) — it's needed to re-derive the key. The IV is unique per letter. Without the passphrase, the ciphertext is indistinguishable from random noise.
