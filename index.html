🔐 How Encryption Works

This app uses mathematically proven, browser-native cryptography. Zero dependencies. Zero servers. Zero tracking.

1. Key Derivation — PBKDF2-SHA256

Your passphrase is fed into PBKDF2 with 310,000 iterations + a random 16-byte salt using SHA-256. This makes brute-force attacks computationally infeasible. Output: a 256-bit key.

2. Encryption — AES-256-GCM

Each letter + photos are encrypted with AES-256-GCM. GCM provides both confidentiality and authentication — any tampering is detected. Each letter has a unique random 12-byte IV.

3. Web Crypto API (SubtleCrypto)

All operations use the browser's built-in SubtleCrypto — the same API used by banks. No JS crypto libraries. Random bytes come from crypto.getRandomValues().

4. Photos — Base64 + AES-GCM

Photos are converted to Base64 and encrypted together with the letter text in the same AES-GCM payload. Even the photo count is hidden from anyone without the passphrase.

📋 Encrypted File Format
{
  "v": 2,
  "salt": "<base64 random 16 bytes>",
  "greeting": "optional name",
  "letters": [
    {
      "iv":    "<base64 random 12 bytes>",
      "ct":    "<base64 AES-256-GCM ciphertext>",
      "emoji": "💌",
      "theme": "cream"
    }
  ]
}

// ct decrypts to JSON:
{
  "occasion": "you're sad",
  "body":     "<rich HTML content>",
  "photos":   ["<base64 image>", ...]
}
